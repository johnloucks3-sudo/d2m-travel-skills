================================================================================
  TROUBLESHOOTING
================================================================================

DAEMON NOT STARTING?
  1. journalctl -u cos-approval-monitor-v2.service -p err -n 50
  2. systemd-analyze verify cos-approval-monitor-v2.service
  3. sudo systemctl daemon-reload
  4. ps aux | grep cos_approval_monitor_v2

NO DETECTIONS FOUND?
  1. Send test email: Subject "[DRAFT] Test", Body "approve"
  2. Wait 60 seconds
  3. Check logs: grep "Approval detected" monitor_v2.log
  4. Check state: cat detection_state.json | jq '. | length'

DUPLICATE PROCESSING?
  1. Check state file: jq '[.[] | .thread_id] | group_by(.) | .[] | select(length > 1)' detection_state.json
  2. Clear state: rm detection_state.json
  3. Restart: sudo systemctl restart cos-approval-monitor-v2.service

HIGH MEMORY USAGE?
  1. Check running processes: ps aux | grep cos_approval_monitor
  2. Restart service: sudo systemctl restart cos-approval-monitor-v2.service
  3. Check logs for leaks: grep WARNING monitor_v2.log

SERVICE WON'T RESTART?
  1. Check disk space: df -h
  2. Check systemd: journalctl -xe
  3. Try: sudo systemctl reset-failed cos-approval-monitor-v2.service
