1. PURPOSE & ARCHITECTURAL OVERVIEW


Temporal is a durable execution orchestration framework designed to make long-running, multi-step asynchronous workflows 100% fault-tolerant. In Thunderbird Wing operations, Temporal serves as the backbone for complex, multi-agent, and scheduled automation pipelines.


Why Temporal?

  • **State Preservation Across Crashes:** If a systemd daemon, subagent, or server reboots mid-workflow, Temporal resumes execution at the exact step where it was interrupted.
  • **Automatic Retries & Exponential Backoff:** Failed API calls (e.g. Centrav, RSSC, Google Flights, Gmail) retry automatically with configurable exponential backoff strategies.
  • **Asynchronous Human-in-the-Loop Gates:** Workflows can pause indefinitely for Commander WF-17 approval before resuming execution automatically.
  • **Auditability:** Every state transition is recorded in Temporal's SQLite event store and visible in the Web UI (`http://localhost:8233`).
