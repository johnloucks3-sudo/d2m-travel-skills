## BOTTOM LINE FIRST

The Commander's instinct is right. The Wing is running on improvised tempo. The exercise framework is the correct fix. But the proposed 7-step sequence — applied universally — will add 30-40 minutes of overhead to tasks that currently resolve in under 5. That overhead is only acceptable if we define "most of what we do" precisely. If we don't, the protocol becomes theater. Here's my honest A5 read.

---

## 1. WHEN DOES A5 ADD VALUE IN THIS SEQUENCE?

A5 pulls value in three specific slots:

**Prompt classification (before the discussion starts):** My job as Operating Tempo Owner is to look at an incoming prompt and ask whether the proposed staff engagement level matches the strategic weight of the task. A booking inquiry routed through a 7-person discussion is waste. A new market entry, partnership proposal, or lifecycle redesign is exactly the right target. I should be the gate that calls that call — "This is a drill-level exercise" or "This is routine ops, skip the sequence." If I'm not making that call, nobody is, and everything gets treated as an exercise.

**During staff discussion — vector check:** When staff are generating options, I'm watching for tactical drift disguised as strategy. Dembe brings a research brief. Luna writes something beautiful. Neither of them is asking: does this move the revenue needle in the next 90 days? That's my question. I surface it during the discussion phase, before Hale synthesizes, while there's still room to redirect.

**Hotwash facilitation:** I should own the hotwash. That's an A5 function — lessons learned translate into doctrine, and doctrine feeds the 1/3/5-year plan. If the hotwash is just a feelings exercise, it dies after the first iteration. I make it a data capture: what changed, what we'd do differently, what time it took versus estimated.

**Conditions where pulling A5 creates drag:** Any prompt under 30 minutes estimated execution time. Any client-facing query (Commander has already exempted these — correct call). Any repeat pattern we've executed 3+ times with documented results. I don't need to be in the room for those.

---

## 2. FAILURE MODES

**Failure Mode 1 — Scope creep on the trigger threshold.** The protocol is designed for major exercises. The moment someone applies it to a "what hotels are available in Lisbon" query, it's dead. We need a hard classification rule with named examples before we launch this. Without it, every prompt becomes an exercise within 2 weeks.

**Failure Mode 2 — Hotwash becomes a graveyard.** We produce a lessons-learned document. It sits in `/output/`. Nobody reads it before the next prompt. The improvement loop never closes. This is the most likely failure — it requires Hale to actively pull the hotwash output into doctrine, and that takes discipline every single time.

**Failure Mode 3 — Token cost explosion.** Full staff discussion on a complex prompt — Dembe research brief, Navarro profile, Reyes recommendations, Luna draft, Naia pass, ELON kill audit comment — could run 15,000-25,000 tokens before Hale synthesizes. At current routing, that's acceptable. If we run 10 major exercises per week, that's 150K-250K tokens in overhead alone. We need a budget cap per exercise type before we scale.

**Failure Mode 4 — Commander decision gates become bottlenecks.** The sequence requires Commander decision before ACTION. If Commander is unavailable for 4 hours, the exercise stalls. We need a defined authority delegation for non-gate decisions — Hale should be able to clear some exercise decisions without pinging Commander.

---

## 3. MINIMUM VIABLE VERSION

Cut the 7-step sequence to 4 tiers based on task weight:

**Tier 0 — Routine (no protocol, current ops):**
- Client queries, repeat patterns, tasks under 30 min estimated execution
- No exercise structure. Just run it.

**Tier 1 — Tactical Exercise (3 steps: Prompt / Hale synthesis / Action):**
- New task type we've done 1-2 times before
- Single staff member engaged — whoever owns that domain
- Hotwash: 3 bullets max, captured by Hale automatically, no meeting

**Tier 2 — Operational Exercise (5 steps: Prompt / Staff discussion 2-3 personnel / Hale synthesis / Commander decision / Action + Hotwash):**
- Cross-functional tasks touching 2+ staff slots
- Hotwash is mandatory but asynchronous — each participant writes 1-2 bullets
- Hale aggregates, documents one principle, updates doctrine file

**Tier 3 — Strategic Exercise (Full 7-step Commander sequence):**
- New market direction, partnership, lifecycle redesign, protocol overhaul
- All relevant staff engaged
- Full hotwash session, formal document improvement cycle
- Estimated overhead: 45-90 minutes — acceptable because the decision is worth it

**The kill threshold:** If Tier 3 exercises are running more than once per week, the classification is broken and we revert to current ops. Volume of major exercises is a red flag, not a sign of progress.

**What I'd cut entirely from the MVP:** The joint force exercise planning parallel is directionally right but adds overhead we can't sustain in a 1-person business operation. The structure is correct. The military nomenclature should stay internal — it gives us precision — but we don't need the full joint exercise documentation apparatus. Keep the *discipline* of exercise planning, not the bureaucracy.
