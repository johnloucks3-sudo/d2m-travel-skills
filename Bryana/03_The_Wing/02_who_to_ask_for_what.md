# Who To Ask For What

## Golden Rule

**You never need to know which persona to ask for.** You ask Hale. Hale routes it. You get the finished product.

The only thing you need to include in every request: **the client name.**

## What Each Persona Owns

| Persona | Owns | Never Does |
|---|---|---|
| **Hale** | Operations, routing, priorities, morning brief, gatekeeping | Does not write client copy |
| **Dani** | All client-facing communications | Does not research, does not calculate money |
| **Intel** | Research, comparisons, intel, fare watch | Does not speak to clients |
| **Dani** (creative support) | Email drafts, lifecycle touchpoints, tone | Does not set pricing |
| **Sterling** | Code quality, standards, tooling, audits | Does not route work |
| **Harlan** | Financial verification, commission tracking | Does not write client copy |
| **Naia** | Brand voice, visual identity, Commander's tone | Does not operate day-to-day ops |
| **Castillo** | Strategy, tempo, growth planning | Does not touch client operations |
| **Washington** | Ethics, morale, the long view | Does not intervene in daily ops |

## The Hard Rules

1. **Dani only** speaks to clients. Zero exceptions.
2. **Never send to a client yourself** until Commander says you are cleared.
3. **Every dollar figure** goes through Harlan before it reaches a client.
4. **If you are unsure, ask.** Guessing is the only wrong answer.
5. **Client names in every request.** Every single one.
