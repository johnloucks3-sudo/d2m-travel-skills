PREREQUISITES
─────────────────────────────────────────────────────────────────────────────
□ d2mconcierge OAuth configured: ~/.credentials/d2mconcierge.json exists
□ Monitor service running: sudo systemctl status cos-approval-monitor.service
□ Directories created: ~/.thunderbird_approvals, ~/Thunderbird/drafts

================================================================================
WORKFLOW: DRAFT → APPROVAL → SEND
================================================================================

STEP 1: CREATE DRAFT (2 minutes)
───────────────────────────────────────────────────────────────────────────────
$ python3 ~/Thunderbird/scripts/create_gmail_draft_direct_v3.py \
    --html ~/Thunderbird/drafts/proposal.html \
    --to johnloucks3@gmail.com \
    --subject "[DRAFT] Your Title Here"

✓ Output: Draft ID (e.g., abc123xyz), saved to ~/.thunderbird_approvals/

STEP 2: FORWARD DRAFT (1 minute)
───────────────────────────────────────────────────────────────────────────────
1. Open Gmail → d2mconcierge account
2. Go to Drafts folder
3. Open the draft
4. Click "Forward"
5. To: johnloucks3@gmail.com
6. Send

STEP 3: COMMANDER APPROVES (2–60 minutes)
───────────────────────────────────────────────────────────────────────────────
Commander opens johnloucks3 inbox, reviews draft, clicks Reply, types "approve", sends.

STEP 4: FINAL DRAFT GENERATED (1–2 minutes automatic)
───────────────────────────────────────────────────────────────────────────────
Monitor daemon polls johnloucks3, detects "approve" reply, auto-generates final draft
in d2mconcierge Drafts folder. Sends notification "Draft Ready for Editing" to johnloucks3.

STEP 5: COMMANDER EDITS & SENDS (1–5 minutes)
───────────────────────────────────────────────────────────────────────────────
1. Open d2mconcierge Gmail
2. Go to Drafts folder
3. Find the draft
4. Edit as needed (full formatting preserved)
5. Click Send

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Monitor service won't start
  → Check: sudo systemctl status cos-approval-monitor.service --no-pager -l
  → Fix: sudo systemctl restart cos-approval-monitor.service

PROBLEM: Draft created but approval not detected
  → Check logs: tail -50 ~/.thunderbird_approvals/monitor.log
  → Verify: Reply was sent to johnloucks3 (not d2mconcierge)
  → Verify: Reply contains word "approve"

PROBLEM: Final draft not created after approval
  → Check: ls -la ~/.thunderbird_approvals/html_{DRAFT_ID}.txt
  → Verify: ~/.credentials/d2mconcierge.json exists and is readable
  → Check logs: tail -50 ~/.thunderbird_approvals/generator.log

PROBLEM: OAuth token expired
  → Fix: python3 ~/Thunderbird/scripts/setup_d2mconcierge_oauth.py
  → Restart: sudo systemctl restart cos-approval-monitor.service

  --html ~/Thunderbird/drafts/proposal_20260503.html \
  --to johnloucks3@gmail.com \
  --subject "[DRAFT] Client Proposal May 2026"

# 3. [Manually] Forward draft from d2mconcierge to johnloucks3

# 4. [Commander] Opens johnloucks3, replies "approve"

# 5. [Automatic] Monitor detects approval, generates final draft

# 6. [Commander] Edits final draft in d2mconcierge, sends
