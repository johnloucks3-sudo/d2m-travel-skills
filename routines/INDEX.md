## How to Install

1. Go to `claude.ai/routines`
2. Click "Create Routine"
3. Set the **slash command** name (e.g., `morning-digest`)
4. Paste the prompt from `routines/morning_digest.md`
5. Set **schedule**: daily at 04:00 MDT
6. Save

> **Note:** Delete or disable the 8 individual routines in claude.ai — they're superseded by `/morning-digest`.
