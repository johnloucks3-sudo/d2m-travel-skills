# Personal Correspondence — Pre-Flight Assumptions Block

**Canonized:** 2026-05-23 | **Origin:** LESSONS_LEARNED.md L3.5 (Westbrook letter error)
**Applies to:** Any personal letter/email drafted FROM Commander to a friend, family member, or close contact.

---

## Protocol

Before drafting ANY personal correspondence from Commander, write an assumptions block in the first response. Format:

```
ASSUMPTIONS FOR [Recipient Name]:
- Commander age: ___ (fact: 72, b. Jul 1953)
- Commander wife: ___ (fact: Susie)
- Recipient relationship: ___ 
- Recipient age: ___
- Any spouse/family names referenced in draft: ___
- Tone: peer / warm-professional / casual
- Advice section included? Yes/No
- [Any other personal detail the draft touches]
```

- **Facts** are looked up before writing (Commander's age, spouse, immediate family).
- **Assumptions** are flagged for Commander to confirm.
- **Unknowns** are marked `[NEED COMMANDER]` — never guessed.
- Commander validates the block → I draft.

## Common Pitfalls (from L3.5)
- Don't assume Commander's age matches the recipient's
- Don't guess spouse name — verify
- Don't write "what I'd do" advice sections — Commander decides what he'd do
- Don't write as staff — write as Commander: specific observations, questions, peer voice
