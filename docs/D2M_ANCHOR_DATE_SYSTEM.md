# D2M ANCHOR DATE SYSTEM
## Dreams2Memories Travel, LLC
### Proposed: 2026-03-07 | Status: DRAFT — Awaiting Commander Review

---

## CONCEPT

Every booking gets a standard set of T-minus milestones, some are specified in the invoice (Excursions open up on XXXX, Start Dining Reservations on XXXXX, Some are calculated backward from **Embark-Date** and some flow forward from **Booking Date**. There is also a **Disembark-Date**  This event-based replaces ad-hoc task tracking with a repeatable, predictable lifecycle that fires automatically for every client, is known by every client. Booking date drives insurance, Client Qualification Form send out.  Embarkation date drives many thins as detailed below. 

---

## 1. MONEY ANCHORS

| Anchor | Formula | Purpose |
|--------|---------|---------|
| **Final_Payment_Date** | Per supplier | Hard deadline — payment or cancellation |
| **T-21before Final Payment** | FPD - 14 | First payment reminder to client |
| **T-14 before Final Payment** | FPD - 7 | Second payment reminder |
| **T-7 before Final Payment** | FPD - 3 | Urgent payment reminder |(Goal for final payment)
| **T+7 after Final Payment** | FPD + 1 | Confirm payment received, update booking status |
| **Commission_Payable** | ~E-30 | Trigger commission audit with host agency |

## 2. CLIENT CARE ANCHORS (Based on **E-Date**) (many needed to be moved back about 2 -3 months)

| Anchor | Formula | Purpose |
|--------|---------|---------|
| **E-270** (9 months out) | Start - 180 | Passport validity check (6-month rule) |
| **e-180** (6 months out) | Start - 120 | Insurance decision deadline / CFAR window |(Deposit Date is the deciding factor for Pre-existing conditions and CFAR.  Needs research)
| **E-150** (3 months out) | Start - 90 | Guest Info Forms collected, dining/excursion selections |
| **E-120** (2 months out) | Start - 60 | Pre-trip call scheduled, specialty dining opens--no this is based on invoice |
| **E-30** (1 month out) | Start - 30 | Final itinerary PDF delivered, all docs confirmed |
Between E-30 and E-3 (flight info, weather, state department reports, sdining reservations, etc)
| **E-14** (2 weeks out) | Start - 14 | Bon Voyage package / final check-in |
| **E+7** (1 week after return) | End + 7 | Welcome Home email |
| **E+14** (2 weeks after return) | End + 14 | Review request (TripAdvisor, Google, Form) |
| **E+30** (1 month after return) | End + 30 | Next trip conversation |
