## THE THREE ZONES

```
ZONE 1 — COMMITMENT          ZONE 2 — PREPARATION         ZONE 3 — EXECUTION
D+0 → T-6mo                  T-6mo → T-30                 T-30 → T+30
"Everything is ahead"        "Details are hardening"      "We are live"
```

**Three Hard Anchors:**
- **DA** = Deposit Accepted → starts the clock
- **FPD** = Final Payment Date → T-120 standard (Oceania/Cunard: T-90 — verify contract)
- **EMB** = Embarkation Date → T-0, immovable

**Pre/Post Standard:** 3 nights pre-embarkation city · 3 nights post-disembarkation city. Always recommended. Always quoted. Client opts out — never opts in.

---

## COMMANDER'S DESIGN DECISIONS (Apr 7, 2026)

1. **Template type:** One universal template with line-specific variances noted inline (not separate per cruise line)
2. **Air handling:** Mix — client decides, we advise either way. Fare watch always runs.
3. **Pre/Post hotels:** Always suggest 3 pre and 3 post as standard recommendation
4. **Fare watch scope:** Air + Hotel (no cruise fare watch)
5. **T-minus anchor:** Three-zone model (Deposit → Final Payment → Embarkation)

## FARE WATCH SPECIFICATIONS

### Air Fare Watch
| Parameter | Spec |
|-----------|------|
| Opens | D+0 — at booking |
| Frequency | Weekly (automated or A2 manual) |
| Alert threshold | −10% from baseline · or business class opens/upgrade available |
| First client delivery | T-12mo (Month 6 in 18-month model) |
| Booking rec window | T-12mo to T-11mo — international business class |
| Final delivery | T-9mo — "book now or accept current fare" |
| Closes | Air booked and confirmed |
| Fallback | If client books own air → switch to "confirm details" role at T-90 |

### Hotel Fare Watch (Pre/Post — 3+3 nights)
| Parameter | Spec |
|-----------|------|
| Opens | D+0 — parallel to air |
| Frequency | Weekly first 3 months · bi-weekly thereafter |
| Alert threshold | Rate drop >15% on cancelable hold · or category upgrade available |
| First client delivery | T-12mo — curated options, 3 properties per city per end |
| Booking rec | T-10mo — luxury properties in peak ports fill 9-12mo out |
| Final rate audit | T-3mo — verify rate, check for upgrade availability |
| Closes | Hotels booked and confirmed |
