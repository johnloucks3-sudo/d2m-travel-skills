# Thunderbird — Session Retros

Auto-generated structured session retrospectives.
Loaded at session start by Hale for continuity bridging.

## Format
Each file: `YYYY-MM-DD-topic.md`
Latest symlink: `_latest.md` (auto-updated by hook)

## Fields
- **Date / Topic**
- **What Worked** — wins, approaches that held
- **What Didn't Work** — errors, blockers, wrong turns
- **Lessons Learned** — rules extracted (feed into CLAUDE.md / memory)
- **Open Loops** — unfinished items to pick up next session
- **Next Priorities** — top 3 actions for next session open

## Load Protocol
Hale loads `_latest.md` at every session open alongside `hale_state.json`.
If retro is >7 days old, flag to Commander.
