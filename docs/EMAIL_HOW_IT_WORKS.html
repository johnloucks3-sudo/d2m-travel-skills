Red Star — Step by Step

1. You're reading an email and want the Wing to act on it

2. Click the star → select red star (hold star icon for color options)

3. Wing scanner fires within 2 minutes

4. You receive a Telegram confirmation with exactly what was done and where data landed

5. Star is automatically removed, email is labeled THUNDERBIRD-RedStarProcessed

If Something Goes Wrong

• No Telegram confirmation after 5 minutes on a red star → check logs/red_star_scanner.log

• Batch reply missing an item → forward it again with red star for immediate processing

• Wing responded "Wilco" but nothing happened → it was queued as a mission; check mission board

• Need the Wing right now → WhatsApp /inbox command
