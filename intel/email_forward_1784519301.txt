2. tmux basics on YOGA

Prefix is remapped to Ctrl-a (not the tmux default
Ctrl-b). One main session; each project or agent gets its own
window; panes are addressed session:window.pane — e.g.
main:3.1 means session main, window 3,
pane 1.

KeysAction

Ctrl-a |Split pane horizontally

Ctrl-a -Split pane vertically

Alt+ArrowSwitch panes (no prefix needed)

Shift+ArrowSwitch windows (no prefix needed)

Ctrl-a rReload ~/.tmux.conf

Ctrl-a pPaste buffer

Middle-clickPaste (mouse mode)

3. Copy mode — scrollback and search

Enter with Ctrl-a [. Vi-style keys inside copy mode:

KeyAction

j / kLine down/up

Ctrl-u / Ctrl-dPage up/down

/  and  ?Search forward / backward

n / NNext / previous match

vBegin selection

yCopy selection and exit

VSelect whole line

Ctrl-vToggle rectangle selection

Ctrl-cExit copy mode

Mouse drag also scrolls/selects (mouse mode is on). OSC52 clipboard is already wired so
browser copy/paste works cleanly through ttyd.

4. Reading another pane or a dev server's output

tmux capture-pane -t main:3.1 -p -S -200   # last 200 lines of that pane
