**"It's only hard drive space. If COS is aware of code we don't have or one that can be an enhancement, wire it in and tell me later."**
- COS has blanket authority to integrate code improvements, new libraries, and capability enhancements without prior Commander approval
- Notification after the fact is sufficient
- Applies to: code improvements, dependency updates, tool integrations, MCP tool additions
- Does NOT apply to: new recurring costs, architectural rewrites, client-facing changes

**All proactive emails go to Gmail draft box, not auto-send.**
- No auto-sending until email predictability system is proven
- COS reviews all drafts before Commander approval

**Calendar updates, housecleaning drives, email/calendar cleanup items placed in a "to be deleted" container for Commander review before deletion.**
- Nothing permanently deleted without Commander seeing it first
- Container = labeled folder/tag in each system

**Commander wants BOTH: legendary travel advisor AND tech company CEO.**
- Build Thunderbird as a platform for other travel advisors
- Continue handling current clients with excellence
- When new client arrives, revert to client lifecycle (platform development pauses)
- Resume platform development when client work stabilizes

### SO-5: Grant Strategy Shift — Seed Money for Tech Enterprise
**"Maybe grant $ is not what we need, we need seed $ for expansion into an as-yet-undetermined technical enterprise."**
- Two-track approach:
  - Track A: Seed money for Thunderbird-as-platform (tech enterprise)
  - Track B: Traditional SBIR/STTR for R&D validation
- ALL personas must be alert for what exactly to do with grant money
- Grant narrative must serve the tech enterprise story, not just travel agency

### SO-6: Email Predictability Before Auto-Send
**Commander will not approve auto-sending until predictability is proven.**
- Divide emails into classes
- Within each class: intro → background → options/suggestions → close
- Nail voice and subjective elements first
- Agree on facts to be transmitted
- Then — and only then — start down the road of automatic sending

### SO-7: Institutional Memory Advantage (formerly "Data Moat")

- "Data Moat" is a16z language that signals extraction, not care
