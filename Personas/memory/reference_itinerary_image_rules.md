# D2M Itinerary Image Rules
## Standing Order — 2026-03-28

---

## Global Rules

1. **No Pexels stock substitutes.** Use actual Silver Nova photography — hull, decks, cabins, dining venues. Stock ocean shots are banned.
2. **Port images must be port-specific** — the actual named port, not regional stock. Must have an interesting subject (not just a skyline or water), must be sunny and well-composed.
3. **Sea day images must show the ship itself** — Silver Nova on open water. No blue-water-only shots.

---

## Day-Specific Rules

| Day / Port | Rule |
|---|---|
| **Embarkation / any day aboard** | Use actual Silver Nova exterior or veranda suite shot |
| **Dining days** | Use photo of the reserved restaurant for that night (La Terrazza / The Grill / Silver Note) |
| **Sea day — Aurora window (high latitudes)** | Reds, greens, and oranges in the frame; shot above the Pacific or Alaskan mountains — not a generic green-curtain shot |
| **Kuril Islands** | If used: MUST be sunny. Do not use overcast/foggy Kurils. |
| **Kodiak Island** | Bear must be full-frame — ideally two bears. Alternate: Kodiak fishing fleet in harbor. |
| **Sitka** | Town set against the mountains. NOT the bridge. Snow, sun, clouds welcome. |
| **Juneau** | Aerial or elevated city view. |
| **Inside Passage (sea day near Alaska)** | Silver Nova cruising wilderness / Inside Passage. NOT a straight-down view of another ship or a generic deck shot. |
| **Victoria, BC** | Empress Hotel exterior, or afternoon tea at the Empress Hotel, or Butchart Gardens. |

---

## Process Rule

**Show all candidate images to Commander before assembly.**
No itinerary is generated until Commander approves or swaps images.
