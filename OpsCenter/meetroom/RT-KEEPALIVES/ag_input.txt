## 2. Consolidation & Isolation Architecture

- **Independent OAuth Layer (MUST stay decoupled):**
  - `claude-oauth` and `google-oauth` (combining d2mconcierge + johnloucks3) MUST run in separate units so token-endpoint rate limits or transient Google auth errors never block Claude MAX CLI/IDE access.
- **Supervisor Layer (`keepalive-supervisor`):**
  - Acts strictly as passive auditor and atomic status writer (`OpsCenter/keepalive_health.json`).
  - Implements **alert deadband / anti-flap**: Transient probe drops (1-2 consecutive misses) log `YELLOW` silently; only sustained multi-cycle failures (`RED`) trigger Telegram/alert escalation.
- **Deduplication:**
  - Remove all duplicate timers from `supertimer_infra_bot_state.json`. `systemd --user` is native Linux ground truth.

---

## 3. Straight-Linux Adaptation (Kill GUI / Browser Hangs)

- **Eliminate Playwright/Chromium from background timers:**
  - `centrav-warm`: Centrav uses Cloudflare/reCAPTCHA + OTP. Automated headless background loops inevitably fail. Replace with explicit on-demand CLI script (`scripts/centrav_reauth.py`) triggered only when token expires.
  - `tess-token`: Pure HTTP REST/Bearer token refresh already functional; remove lingering Playwright fallback paths.
  - `perx` & `bsk`: Convert to pure HTTP requests/cURL sending stored session cookies and inspecting HTTP response codes (200 OK vs 302/401 redirect).
