### 1. Root Cause Analysis: Headless `claude -p` Hangs

* **Environment Pollution (`ANTHROPIC_API_KEY`)**: When `ANTHROPIC_API_KEY` is set in parent env (even if invalid/expired), `claude` CLI prioritizes it over `CLAUDE_CODE_OAUTH_TOKEN`. In non-interactive mode without TTY, API key auth failure prints `Invalid API key` and hangs or exits ungracefully.
* **Retired/Invalid Model Identifier**: Anthropic retired `claude-3-5-haiku-20241022` on Feb 19, 2026. Passing outdated model date strings or unmapped aliases forces `claude` CLI to output model catalog warnings and wait for model selection input. Pinned model aliases must be `haiku`, `sonnet`, or `opus` (or active canonical IDs).
* **Unclosed STDIN in Popen Background Spawns**: Background subprocesses (`_spawn_background` in `thunderbird_headless_spawn.py`) launched without `stdin=subprocess.DEVNULL` hang waiting for EOF on inherited stdin pipes.
* **Unresponsive MCP Host Init**: Omitting `--mcp-config` or `--strict-mcp-config` causes `claude` CLI to initialize all user MCP servers, hanging if any server blocks.

**Ground Truth Test Verified:**
* Test A (with `ANTHROPIC_API_KEY` active): `claude -p "Say test"` → Failed with `Invalid API key` (code 1).
* Test B (with `env.pop("ANTHROPIC_API_KEY")` + `CLAUDE_CODE_OAUTH_TOKEN` + `--model sonnet`): Executed cleanly in 8.1s (`STDOUT: Hey there, Yoda!`, returncode 0).
* Test C (with `env.pop("ANTHROPIC_API_KEY")` + `CLAUDE_CODE_OAUTH_TOKEN` + `--model haiku`): Executed cleanly in 11.2s (`STDOUT: Hello, Commander. Standing by.`, returncode 0).
