# MISSION-814 Fix Plan — CC-Fleet Groq/Cerebras Provider Fix
*Implemented 2026-07-02 by Hale (Claude Code)*

## Status: CEREBRAS ✅ PASS | GROQ ⚠️ PARTIAL (free-tier TPM wall)

---

## Root Cause (confirmed from prior diagnosis)
cc-fleet sets `ANTHROPIC_BASE_URL=https://api.groq.com/openai/v1` and the spawned `claude`
binary calls `POST /v1/messages` (Anthropic format). Groq/Cerebras only serve
`POST /chat/completions` (OpenAI format). Every subagent → HTTP 404.

---

## Fix Architecture

```
cc-fleet claude binary
    │  ANTHROPIC_BASE_URL=http://localhost:4000
    │  Authorization: Bearer sk-ant-d2m-gateway-key
    ▼
LiteLLM Proxy (:4000)  ← ~/.claude/gateway/litellm_config.yaml
    │  translates POST /v1/messages → POST /chat/completions
    │  routes by model name alias
    ├─ llama-3.3-70b-versatile → groq/qwen/qwen3-32b
    └─ cerebras-gemma          → cerebras/gemma-4-31b
    ▼
Groq / Cerebras APIs
```

## Model Decisions

### Cerebras
- `gpt-oss-120b` — reasoning-only, returns `thinking` blocks with empty `content[text]`. cc-fleet fails silently.
- `zai-glm-4.7` — also reasoning-only.
- **`gemma-4-31b`** — standard text generation. **WORKS.** Used for all Cerebras slots.

### Groq
- All free-tier models have TPM limits (6K–12K) far below cc-fleet's slim prompt (36K) and full prompt (85K).
- `drop_params: true` required — Groq rejects `prompt_cache_key` (Anthropic-only param).
- **`qwen/qwen3-32b`** — responds on simple prompts; still rate-limited on cc-fleet full runs.
- **GROQ REQUIRES PAID TIER** for cc-fleet reliability. Free tier is insufficient.
