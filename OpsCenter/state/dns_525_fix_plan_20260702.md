## Fix Plan — Two Paths (choose one)

### PATH A — Cloudflare "Flexible" SSL Mode (fastest, 5 min, no certbot)
**Recommended for immediate restoration. Trade-off: Cloudflare→origin is HTTP, not HTTPS. Acceptable for internal dashboard on Cloudflare tunnel.**

1. **Cloudflare Dashboard** → d2mluxury.quest → SSL/TLS → Overview
2. Set SSL mode to **"Flexible"** (was "Full Strict")
3. Restart origin service on YOGA:
   ```bash
   systemctl --user start d2m-dashboard.service
   systemctl --user status d2m-dashboard.service
   ```
4. Test: `curl -I https://d2mluxury.quest` → expect HTTP 200

**Why this works:** Cloudflare→user TLS stays intact (Cloudflare holds the cert). Cloudflare→origin uses HTTP to :8901 (tunnel encrypts the Cloudflare-to-origin leg). No origin cert needed.

**Risk:** Slightly lower security posture for the Cloudflare→origin hop. Acceptable for non-PCI traffic.
